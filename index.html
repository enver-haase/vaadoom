VAADOOM

DOOM running in WebAssembly — a NOMMU Linux on Adrian Cable's single-instruction SUBLEQ VM. This is a standalone demo of the client engine; the Vaadin Directory add-on wraps this exact engine as a server-side Flow component. Click the frame and play. First paint takes ~15 seconds (it boots Linux, then launches DOOM).
